## 일반 질문 {#general-questions}

### Q: 어떤 Revit 버전을 지원하나요?
**A:** Visibility Manager는 Revit 2023, 2024, 2025, 2026을 지원합니다. 각 버전에 최적화된 전용 빌드가 있습니다.

### Q: 템플릿과 함께 작동하나요?
**A:** 네! 도구는 뷰가 템플릿을 사용하는지 자동으로 감지하고 템플릿에서 필터 설정을 자동으로 읽습니다. 필터를 복사할 때 뷰에 직접 적용하거나 템플릿에 적용할 수 있습니다.

### Q: 다른 프로젝트 간에 사용할 수 있나요?
**A:** 물론입니다! 한 프로젝트에서 필터를 내보내고 다른 프로젝트로 가져올 수 있습니다. 도구가 누락된 매개변수와 패턴을 자동으로 처리합니다.

## 워크플로우 및 작업 {#workflow--operations}

### Q: COPY 기능은 어떻게 작동하나요?
**A:** COPY는 현재 뷰에서 선택한 필터 또는 VG 재정의를 대상 뷰/템플릿으로 복제합니다.

**핵심 사항:**
- **현재 뷰 = 소스 (참조만)** — 복사할 내용을 보여주지만 수정되지 않음
- **열 2-3 = 대상** — 필터/재정의가 복사되는 곳
- 필터와 VG 재정의 모두 동일하게 작동

**단계별:**
1. 복사할 필터/재정의가 있는 뷰 열기 (소스)
2. **왼쪽 패널**: 복사할 필터 또는 재정의 선택
3. **열 2**: 대상 뷰 선택
4. **열 3**: 대상 템플릿 선택 (선택사항)
5. **COPY** 클릭
6. 항목이 이미 존재하는 경우 충돌 해결 선택:
   - **Merge** — 기존 유지, 새 항목만 추가
   - **Overwrite** — 기존을 가져온 설정으로 교체
   - **New Only** — 기존 건너뛰기, 새 항목만 추가

**참고:** 현재 뷰는 절대 수정되지 않습니다 — 참조용입니다!

---

### Q: REMOVE 기능은 어떻게 작동하나요?
**A:** REMOVE는 대상 뷰/템플릿에서 선택한 필터 또는 VG 재정의를 삭제합니다.

**핵심 사항:**
- **현재 뷰 = 참조만** — 제거할 내용을 보여주지만 수정되지 않음
- **열 2-3 = 대상** — 필터/재정의가 제거되는 곳

**사용 사례:** 여러 뷰에서 오래된 필터를 한 번에 제거하여 정리합니다.

---

### Q: 대상 뷰가 템플릿을 사용할 때 어떻게 되나요?
**A:** 도구가 **자동으로 템플릿을 감지**하고 경고를 표시합니다:
- 감지된 템플릿 이름
- 각 템플릿을 사용하는 뷰 수
- 영향을 받을 총 뷰 수

**왜?** Revit에서 뷰가 템플릿을 사용할 때 필터/VG 설정은 템플릿에 의해 제어됩니다. 이것은 도구의 제한이 아닌 Revit의 동작입니다.

---

### Q: 뷰(열 2)를 선택해야 하나요, 템플릿(열 3)을 선택해야 하나요?
**A:** 둘 다 작동합니다:

**열 2 — 대상 뷰:**
- 이름별로 뷰 선택
- 뷰가 템플릿을 사용하는 경우 → 도구가 템플릿에 적용 (먼저 경고)
- 뷰에 템플릿이 없는 경우 → 해당 뷰에만 적용

**열 3 — 대상 템플릿:**
- 직접 템플릿 선택
- 대량 표준화에 더 효율적
- 더 명확한 의도 — 템플릿을 수정하고 있다는 것을 알 수 있음

## 내보내기/가져오기 {#exportimport}

### Q: 내보내기는 어떻게 작동하나요 — 어떤 뷰가 소스인가요?
**A:** 내보내기는 **현재 활성 뷰** (패널 ❶)에서 필터/VG 재정의를 캡처합니다.
- 필요한 항목 선택
- EXPORT 클릭
- 저장 위치 선택
- 현재 뷰 변경 없음

### Q: 가져오기는 어떻게 작동하나요 — 어떤 뷰가 영향을 받나요?
**A:** 가져오기는 **현재 활성 뷰**에 적용됩니다:
- 뷰가 템플릿을 사용하는 경우 → 템플릿에 적용, 이를 사용하는 모든 뷰에 영향
- 뷰에 템플릿이 없는 경우 → 해당 뷰에만 적용

**COPY와의 중요한 차이:**
- **COPY**: 여러 대상 뷰 선택. 현재 뷰 변경 없음
- **IMPORT**: 현재 뷰만 대상. 현재 뷰가 변경됨

### Q: 도구가 Excel과 함께 .PAT 파일을 내보내는 이유는?
**A:** Revit 채우기 패턴은 필터와 별도로 저장됩니다. .PAT 파일에는:
- 필터에 사용된 모든 채우기 패턴
- 패턴 정의 (선, 각도, 간격)
이를 통해 다른 프로젝트로 필터를 가져올 때 모든 패턴을 사용할 수 있습니다.

### Q: 가져오기 중 .PAT 파일이 없으면 어떻게 되나요?
**A:** 도구가 경고를 표시하지만 계속 진행됩니다:
- 필터가 성공적으로 가져와짐
- 패턴을 수동으로 로드할 때까지 "Pattern not found" 표시
- 권장: .PAT 및 .XLSX 파일을 항상 함께 보관

### Q: 가져오기 전에 Excel 파일을 편집할 수 있나요?
**A:** 네! 가능합니다:
- ✓ 필터 이름 수정
- ✓ 색상, 선 두께 변경
- ✓ 규칙 값 업데이트
- ⚠️ 열 구조나 헤더 이름은 변경하지 마세요

### Q: Excel과 CSV 중 어떤 것을 사용해야 하나요?
**A:**
- **Excel (.xlsx)** — 권장! 더 나은 서식, 읽기 쉬움
- **CSV** — 레거시 시스템이나 버전 관리 (Git 호환)에 사용

### Q: 이전 Revit 버전에서 만든 필터를 가져올 수 있나요?
**A:** 네! 도구가 API 차이를 자동으로 처리합니다. Revit 2023에서 내보낸 필터가 Revit 2026에서 완벽하게 작동하며 그 반대도 마찬가지입니다.

## 성능 {#performance}

### Q: 한 번에 몇 개의 필터를 복사할 수 있나요?
**A:** 100개 이상의 필터를 50개 이상의 뷰에 동시에 테스트했습니다. 실질적인 제한이 없습니다!

### Q: Revit 속도가 느려지나요?
**A:** 아닙니다. 작업이 최적화되어 Revit API를 효율적으로 사용합니다. 50개 필터 복사에 약 5초 소요됩니다.

## 문제 해결 {#troubleshooting}

### Q: 가져오기가 "Success"라고 하는데 뷰에 필터가 나타나지 않습니다
**A:** 확인 사항:
1. 필터가 활성화되어 있나요? (View → Visibility/Graphics → Filters 탭)
2. 뷰가 이 필터를 포함하지 않는 템플릿을 사용하고 있나요?
3. 필터 카테고리가 뷰의 요소와 일치하나요?

### Q: 필터가 가져와지지만 실제 값 대신 "Value"가 표시됩니다
**A:** v1.0.0의 버그로, v1.0.1에서 수정되었습니다. 최신 버전으로 업데이트하세요.

### Q: 가져오기 후 "Pattern not found" 경고
**A:** .PAT 파일이 가져오지 않았거나 다른 위치에 있습니다. 다시 가져오고 .PAT 파일이 .XLSX 파일과 같은 폴더에 있는지 확인하세요.

### Q: 가져오기 중 사용자 정의 매개변수가 생성되지 않았습니다
**A:** 사용자 정의 매개변수 대화상자에서 "Yes"를 클릭했는지 확인하세요. "No"를 클릭하면 매개변수가 생성되지 않습니다.

## 팁 및 모범 사례 {#tips--best-practices}

### Q: 필터 정리에 대한 팁이 있나요?
**A:** 네!
- 일관된 명명 사용: 분야별 접두사 (ARCH_, STRUCT_, MEP_)
- 필터 세트를 Excel로 내보내서 문서화
- 사무소 표준 필터가 포함된 마스터 템플릿 생성
- 설명적인 이름 사용, "Filter1", "Filter2"가 아닌

### Q: 조정 회의를 위한 필터는 어떻게 설정하나요?
**A:**
1. 각 분야별 필터 세트 생성
2. 모든 세트를 Excel로 내보내기
3. Excel 파일을 조정 팀과 공유
4. 각 분야가 관련 필터 가져오기
5. 모두 동일한 뷰 설정을 갖게 됩니다!

### Q: Revit 템플릿에 이것을 사용할 수 있나요?
**A:** 물론입니다! 일반적인 워크플로우:
1. 테스트 프로젝트에서 완벽한 필터 구축
2. Excel로 내보내기
3. 회사 템플릿으로 가져오기
4. 모든 프로젝트에 템플릿 배포
